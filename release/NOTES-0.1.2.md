# SolidRPC agent toolkit 0.1.2

- The desktop MCP bundle includes patched Hono dependencies for upstream HTTP server advisories.
- Installation now starts with the published npm package and recommends the latest patch of a supported Node.js LTS release.

```sh
npm install --global @solidrpc/agent@0.1.2
solidrpc --version
```

See the [agent setup guide](https://solidrpc.io/docs/agents) for management token and MCP configuration. The release includes the npm tarball, desktop MCP bundle, source ZIP, and SHA-256 checksums.
